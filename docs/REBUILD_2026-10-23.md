## 続く改善候補

1. **本番の復旧**: 旧 Render 本番・SIT URL は 2026-10-23 の HTTP 確認でどちらも 404（`x-render-routing: no-server`）。確認用無料サービスは起動したが、認証・AI・購入検証に必要な環境変数は未設定。本番サービスと配備先を決め、必要な秘密設定を安全に復元する。接続先が決まったら Android CI の `VITE_API_BASE` と `RENDER_PROD_SERVICE_ID`、デプロイワークフローの旧URL参照を更新する。
2. **ストア公開の条件**: 12人以上のテスターによる14日以上のクローズドテストと、お支払いプロファイルの本人確認が必要。Play Console に新しい AAB を提出して Billing Library のポリシー問題が消えるか確認する。復元済みプロジェクトにはリリース署名用 `key.properties` がない。CI は署名用シークレットを参照するが、現在も有効かは未確認。
3. **初回体験の実機検証**: 診断、レッスン完了、ジャーナル登録、購入を Android/iOS 実機で通し確認する。今回の手動確認はローカル Web のゲスト状態。
4. **表示性能**: 学習一覧とプロフィールを遅延読込に変更し、`AppV3` の JS チャンクを約 530 kB から約 361 kB へ縮小。350 kB 警告はわずかに残り、次の分割候補を検討する。
5. **コンテンツの整理**: 41コースを7つの目的で絞り込む導線を実装済み。選択した目的の最初のレッスンを開始カードに表示する。初回に提示する学習範囲の実利用検証は継続する。
6. **実装の整理**: 画面内インラインスタイルが多く、共通コンポーネントの調整がしにくい。トークンとコンポーネントへ段階的に集約する。
