「ダブり」はなぜ起きるのか

分類した項目どうしが重なっていると、同じ話を二度数えてしまいます。たとえば顧客を「新規」「20代」と分けると、20代の新規客がどちらにも入ってしまいます。

図解：重なり合う集合（ダブりの可視化）

重なりをなくす鍵は、分ける「軸」をひとつに保つことです。年齢で分けるなら最後まで年齢で、契約状態で分けるなら契約状態で揃えます。

✓ 良い例新規 / 既存（契約状態の1軸）
✕ 悪い例新規 / 20代（軸が混在）
◎
要点：分類は「軸をひとつ」に保つとダブりが消えます。

慣れるまでは、分けたあとに「どれか2つに同時に当てはまる人はいないか？」と一度だけ問い直すのがおすすめです。
