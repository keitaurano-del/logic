# Logic ドッグフーディング Phase 1 — テストペルソナ設計

作成日: 2026-05-30 / 担当: content-creator
目的: 多様な20ペルソナで Logic を使い倒し、UI・機能・オンボーディング・課金導線の改善点を洗い出す。改善は最終的にアプリ内フィードバック（機能追加 / バグ報告 / UI改善 / コンテンツ / その他）から起票する。本ドキュメントは実態に即したペルソナ設計のみを行い、コード・本番DBには触れない。

---

## 0. 前提: アプリの実機能サマリー（憶測でなくコードベース確認済み）

ペルソナ設計はこの実機能セットに基づく。

### 画面構成（src/screens/）
- ホーム（HomeScreenV3）: 今日のフェルミ1問、おすすめレッスン、学習時間、ストリーク導線
- ロードマップ（RoadmapScreenV3）: 42コース / 7グループ / 30+カテゴリ、AI検索、カスタムコース、ピン留め、進捗バッジ
- レッスン（Lesson）: explain / quiz ステップ、図解（SVG diagram）、TTS読み上げ、コース連続再生
- フェルミ: ホームの「今日の1問」、デイリーフェルミ、履歴、ランキング（AIスコアリング）
- 復習ハブ（ReviewHub）: フラッシュカード（SM-2 SRS）、間違えた問題、フェルミ履歴、保存アイテム ← 有料限定
- ジャーナル（Journal）: AIアシスタント、カレンダー、検索、ジャーナル専用ストリーク ← 有料（7日間無料トライアル）
- AI問題生成（AIProblemGen）: 弱点ベース自動生成 ← 有料限定
- コーヒーブレイク（CoffeeBreak）: ロールプレイ・シナリオ
- プロフィール（ProfileV3）: ストリーク、完了数、XP / レベル（Lv100+）、ランク、称号、学習時間、保存、完了レッスン
- 料金（Pricing）/ サブスク管理、設定（アカウント・通知・外観・言語）、配置診断（PlacementTest）→ パーソナルコース生成
- フィードバック（Feedback）: 5カテゴリ送信フォーム

### 課金（単一有料プラン）
- 無料: 全レッスン閲覧可 + フェルミ1日1問 + 学習記録・ストリーク・XP
- 有料 月¥350 / 年¥2450（約42%OFF）: フェルミ1日10問 + 復習ハブ + AI問題生成 + ジャーナル
- ジャーナルは初回7日間無料トライアル

### オンボーディング / 認証
- 認証: マジックリンクのみ（メール→リンクタップ）。OTP・Googleログインなし
- オンボーディング: 生年（birthYear）→ 性別（gender）→ 職業（occupation 9種: 経営・役員 / コンサルタント / 企画・事業開発 / 営業・マーケ / エンジニア・IT / 管理部門 / 専門職 / 学生 / その他）→ 料金提示画面
- 配置診断: 軸別（axis）診断 → レベル判定 → パーソナルコース生成
- 多言語: ja / en

### コース体系（7グループ）
論理的に考える / 課題を解決する / 発想を広げる / 相手を動かす / 現場で実践する / コンディションを整える / キャリアを築く

### 各ペルソナの「引っかかる/不満を持ちそうな」ポイント仮説（改善の種）

- p01 佐藤ハル: 無料だと復習ハブ・AI生成が使えず「せっかく解いた問題を復習できない」フラストレーション → 課金導線の納得感。SPI/玉手箱/ケースが別コースに散在し、就活目的で横断しづらい。
- p02 田中ミオ: ジャーナル7日トライアルの残日数・期限表示が分かりづらい → トライアル終了の不意打ち。AIアシスタントの使い方が初見で不明。
- p03 鈴木ケンタ: 週末しか開かないとストリークが途切れる → ストリーク仕様（毎日前提）が週末型に厳しい。おすすめレッスンが毎回ランダムで「続き」に戻りづらい。
- p04 高橋アヤ: フェルミ1日10問でも上級者には足りない可能性 → 上限の手応え。ランキングの母数・更新頻度・スコア基準の透明性。
- p05 伊藤ダイ: 図解（SVG）の情報密度・正確性に厳しい → 図と本文の食い違いに気づく。Android特有のレイアウト崩れ。
- p06 渡辺サキ: AI問題生成の生成速度・弱点判定精度に期待 → 生成中の待ち体感、生成結果の質。
- p07 山本ジン: タブ構成・戻る導線が分からず迷子 → 情報設計・ラベルの直感性。文字が小さいと感じる。
- p08 中村リカ: すぐ離脱するので通知が復帰トリガー → 通知設定の初期値・頻度。哲学/東洋思想コースの導入の敷居。
- p09 小林タク: カスタムコース・保存・iPad横画面の使い勝手 → レスポンシブ崩れ、Web/モバイル間の同期。
- p10 加藤ノゾミ: 保存アイテムが多くなると一覧管理がつらい → 保存の整理・検索。ロジカルライティング系の実務適用感。
- p11 吉田ハヤト: ストリーク途切れの喪失感が強い → ストリーク復活・猶予の有無、連続記録のモチベ設計。
- p12 山田エリ: 夜間に短時間・中断が多い → 学習時間計測の途中離脱挙動、再開のしやすさ。ダークモード/外観。
- p13 佐々木リョウ: ランキング順位・スコアの伸びにこだわる → スコア算出の説明、デイリー上限到達後の物足りなさ。
- p14 松本カナ: ラテラル/アナロジーをつまみ食い → コース途中離脱からの再開導線、おすすめの当たり外れ。
- p15 井上ソウ: 効率重視でTTS連続再生・速読 → TTS品質・速度調整、コース連続再生の安定性。
- p16 木村ユイ: 配置診断の結果・パーソナルコースの納得感 → 診断のレベル判定が腑に落ちるか、完璧主義ゆえ「全部初級判定」等に動揺。
- p17 林タケシ: 高年齢・大画面、文字サイズ・コントラスト → アクセシビリティ、外観設定の発見性。離脱しやすい導線。
- p18 清水アオイ: 通知の多さ・割り込みに敏感 → 通知の細かい制御、ADHDレバレッジコースの当事者目線の質。
- p19 森ハナ: 解説を熟読、自信回復目的 → フィードバック文言のトーン（責めない中立性）、難易度の段階。
- p20 岡田ケイ: en locale で全画面を使う → 未翻訳・翻訳崩れ・日本語特有データ（フェルミの「日本人口」等）の英語側整合。
